Jev 大模型识妖

按意思识别，不是按词匹配。换个说法、拆开写、用缩写代称，照样照出来。

五大内置阵地

微博 / 小红书 / 知乎 / 淘宝天猫 / 京东开箱即照，每个平台独立开关，不勾的站页面完全不动。

三档火力

0.8 只抓铁证 · 0.6 灵敏均衡 · 0.4 宁可错杀，按口味自己调。

两种照法

「亮牌照妖」亮徽标不拦你读；「直接收走」折叠 / 模糊 / 盖一层，看不惯的一秒清场。

本地缓存省钱

同一段内容只照一次，结果存本地。列表滚动、React 重挂，靠「身份指纹」免于重复照、重复计费。

隐私零收集

key 只存你自己电脑；无账号、无埋点。不勾的平台、没挂规则的网站，脚本完全静默，页面零改动。

安装与开光

三步，全程免费不用注册本站账号，key 只存你本机

装扩展

地址栏输入 chrome://extensions 回车 → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选中本仓库文件夹。

✓ 十秒钟装完

领 key

点浏览器右上角照妖镜图标 → 切到「key 设置」页 → 点「哪里领 key」跳转 Jev 官网 docs.typesafe.ai，注册领一个。

✓ 请求量、计费以 Jev 官方为准

开光

把 key 贴进镜心，点「开光」。扩展拿一句测试广告语现场验 key，成功后提示「识破把握 xx%」。默认直连 api.typesafe.ai，也可自定义中转地址。

✓ key 不上传给任何人

装好扩展 → 开着它刷十分钟小红书或淘宝评论 → 回来看效果

任意网站

写几行 CSS，挂上去照两类规则：广告标识（走模型）· 屏蔽列表（纯关键词）

遇到内置名单之外的网站？不用等作者更新——F12 找到选择器，照着格式填进弹窗「自定义」页，规则当场生效。

「广告标识」规则把内容发给 Jev 判定、亮牌、可一键收走；「屏蔽列表」规则撞到关键词直接处理，不过模型、不费 key。

支持「选择器@属性」写法（如 a@href 取链接当指纹），React 列表重挂也不会重复照。

完整填写教程（F12 找选择器、字段逐个说明、IT 之家实战样例、常见问题）见仓库里的 广告照妖镜介绍.txt 第四章。

问答

上手前最常问的四件事更多问题见介绍文章第五章与 FAQ

会误伤正常内容吗？

有一定概率。徽标是模型的概率判断，存在误判和漏判，仅供参考，不是权威鉴定。嫌吵就把火力调到 0.8 只抓铁证；嫌漏就把「直接收走」改回「亮牌照妖」，先观察几天再决定收不收。

费 key 吗？大概多少量？

只对被照的条目请求判定，同一段内容本地缓存后不重复请求；「屏蔽列表」类规则完全不请求。不勾的平台、没挂规则的网站一分不花。具体额度以 Jev 官方为准。

支持哪些浏览器？

基于 Chrome MV3，Chrome / Edge 等 Chromium 系可用（Edge 在 edge://extensions 里同样开开发者模式加载）。Firefox 与 Safari 未适配。

我的 key 和浏览数据安全吗？

key 只存你本机浏览器；除把被照条目文字发给你在「key 设置」里填的判定接口外，无账号、无埋点、不收集其它数据。开源代码可自行审阅。
