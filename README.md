# 广告照妖镜

> 照一照，广告现原形。

免费开源的 Chrome 扩展：用 [Jev](https://docs.typesafe.ai) 大模型实时识别网页里的
硬广、软广、引流帖、水军评论与 AI 生成内容，在内容旁边亮出「照妖徽标」，
还能一键折叠、模糊、盖住收走。

- 内置微博 / 小红书 / 知乎 / 淘宝·天猫 / 京东 五大阵地，各自独立开关
- 电商评论区特化文案「疑似刷评」：好评返现、刷单水军、AI 批量评论一眼分清
- 任意网站写几行 CSS 规则即可挂上去照，无需改代码、无需发版
- key 只存你自己电脑；无账号、无埋点、零收集
- 判定结果本地缓存，同一段内容不重复请求、不重复计费

## 安装（三步）

1. **装扩展**
   地址栏输入 `chrome://extensions` 回车 → 打开右上角「开发者模式」→
   「加载已解压的扩展程序」→ 选中本仓库文件夹（`manifest.json` 所在这层）。

2. **领 key**
   点浏览器右上角照妖镜图标 → 切到「key 设置」页 → 点「哪里领 key」
   跳转 [docs.typesafe.ai](https://docs.typesafe.ai)，注册领一个。
   请求量与计费规则以 Jev 官方为准。

3. **开光**
   把 key 贴进镜心，点「开光」，扩展会用一句测试广告语现场验 key，
   成功后提示「识破把握 xx%」。
   默认直连 `https://api.typesafe.ai/v1/systemone`，也可在「换一条路」里
   填自定义中转地址。

| 社媒 | 小红书 | 笔记详情页 · 首页瀑布流卡片 | 独立 |

（电商场景为 **真实评论 / 疑似刷评**）。不勾的平台页面完全不动。

## 自定义网站规则

名单之外的网站不必等更新——F12 找到选择器，填进弹窗「自定义」页即可：

- **广告标识**：条目发给 Jev 判定 → 亮牌 → 可一键收走（走模型，费 key）
- **屏蔽列表**：撞到关键词直接处理（纯本地，不费 key）

支持「选择器@属性」指纹写法（如 `a@href`）。完整填写教程、字段说明与
常见问题见《广告照妖镜介绍.txt》第四章。

## 隐私与花费

- key 只存你本机浏览器，不上传给任何人
- 仅将被照条目的文字发送到你在「key 设置」里填的判定接口
- 判定结果本地缓存；列表滚动、React 重挂靠「身份指纹」免于重复照
- 无账号、无埋点、不勾的平台一分不花
